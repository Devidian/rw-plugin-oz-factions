# OZ - Factions 0.1.0

- Players can found, join and manage factions with applications, member roles,
  faction permission groups and same-faction PvP protection.
- Each faction receives its own account. Members can deposit any configured
  Wallet currency, and dissolution transfers every positive balance safely to
  the world account.
- Founders can choose a faction color, and leaders can change it later.

Requires OZ Tools 0.24.11. OZ Wallet is optional, but required for faction
foundation costs and faction accounts.
